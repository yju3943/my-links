# AI 기초 한 장 정리

## 1. AI란?

사람이 하던 판단·인식·생성 작업을 컴퓨터가 데이터로부터 **규칙을 배워서** 수행하는 기술.
전통적인 프로그램은 사람이 규칙을 직접 짜지만, AI는 데이터에서 규칙을 스스로 찾아낸다.

```
전통 프로그래밍:  규칙 + 데이터  →  답
머신러닝:        데이터 + 답    →  규칙(모델)
```

## 2. 용어 정리

| 용어 | 뜻 |
|------|-----|
| AI | 지능적 작업을 수행하는 시스템 전체를 아우르는 말 |
| 머신러닝(ML) | 데이터로 학습해 성능이 좋아지는 AI의 한 갈래 |
| 딥러닝 | 인공신경망을 여러 층 쌓아 학습하는 ML 기법 |
| LLM | 방대한 텍스트로 학습해 다음 단어를 예측하는 대규모 언어 모델 |
| 생성형 AI | 글·이미지·코드 등 새로운 결과물을 만들어내는 AI |

## 3. LLM은 어떻게 동작하나

1. **토큰화** — 문장을 단어보다 작은 조각(토큰)으로 자른다.
2. **예측** — 지금까지의 토큰을 보고 다음 토큰의 확률을 계산한다.
3. **생성** — 확률에 따라 토큰을 하나씩 이어 붙여 문장을 완성한다.

즉 LLM은 "정답을 찾아오는" 것이 아니라 **가장 그럴듯한 다음 말을 이어 쓰는** 모델이다.
그래서 사실과 다른 내용을 자신 있게 말하는 **환각(hallucination)** 이 생긴다.

## 4. 잘 쓰는 법 (프롬프트 기본기)

- **역할과 목적을 준다** — "너는 코드 리뷰어다. 버그만 지적해라."
- **구체적으로 쓴다** — "짧게" 대신 "3줄 이내로".
- **예시를 넣는다** — 원하는 출력 형식을 한두 개 보여주면 정확도가 크게 오른다.
- **맥락을 붙인다** — 관련 문서·코드를 함께 주면 환각이 줄어든다.
- **단계를 나눈다** — 큰 요청 하나보다, 나눠서 확인하며 진행하는 편이 정확하다.

## 5. 활용 분야

- 문서 요약·번역·초안 작성
- 코드 생성, 리뷰, 리팩터링, 테스트 작성
- 고객 응대 챗봇, 사내 지식 검색(RAG)
- 이미지·음성 생성 및 인식
- 데이터 분류, 이상 탐지, 수요 예측

## 6. 주의할 점

- **사실 검증 필수** — 숫자, 인용, 법·의료 정보는 반드시 원본 확인.
- **개인정보·기밀 입력 금지** — 입력한 내용이 어디에 저장되는지 확인하고 쓴다.
- **편향** — 학습 데이터의 편향이 결과에 그대로 나타날 수 있다.
- **저작권·라이선스** — 생성 결과물의 권리 관계를 확인한다.
- **최종 책임은 사람에게** — AI는 초안을 만드는 도구, 판단은 사람이 한다.

---

> 한 줄 요약: AI는 데이터에서 패턴을 배워 그럴듯한 답을 만들어내는 도구다.
> 빠르게 초안을 얻되, 검증은 사람이 한다.
